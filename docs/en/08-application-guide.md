## Start with roles, then choose appearance

Build around a division of information: headings establish topics, body text explains value, contents help orientation, controls support action, and code or examples support execution. Then choose colors, typography, and decoration for the content and brand.

## Match the combination to the task

| Your page | Useful combination | Decisions to make for your project |
|---|---|---|
| Company introduction | Clear statement, selected content, open composition | Narrative tone, imagery, distinctive information |
| Product introduction | Clear heading, scenarios, prioritized main action | Credible demonstrations, signed-out and signed-in routes, trial or purchase requirements |
| Resource library | Categories, search, topic labels, reading time | Categories matching how readers seek content |
| Technical docs | Navigation tree, article, contents, code copying, steps | Versions, runnable examples, error recovery, migrations |
| Course | Goals, duration, video and text, next step | Exercises, progress, completion conditions, text alternatives |
| Developer blog | Compact rows, dates, categories, technical labels | Whether retro imagery suits the audience and remains readable |

## Define your own typographic roles

Choose the roles before deciding how many fonts you need:

1. **Display and headings.** Give them identity while supporting real title lengths and the target language.
2. **Reading and controls.** Prioritize clear, stable body text, navigation, and buttons with suitable language coverage.
3. **Code and structured information.** Use monospace for code, commands, and content requiring alignment.

Check font licensing, loading cost, and character coverage together. See the [materials notice](../../NOTICE.md) for this project's asset scope.

For Chinese headings, use real content to choose size: check length and character density, then refine line breaks, line height, and narrow layouts so headings remain proportionate to the body.

## Let color express hierarchy

Use a small number of background levels, high-contrast primary text, and distinct roles for emphasis, states, and syntax. Links, warnings, decoration, and selection convey different meanings; color choices should make those meanings distinguishable.

Check body text, secondary text, fine borders, and controls together, including hover, focus, and disabled states.

## Let the task determine density

Marketing pages can give a large area to one message. Knowledge pages need continuing orientation and a next step. Action-heavy tools need space for parallel information and repeated operations. Density should match task complexity.

Sketch the reader's task sequence before assigning space:

| Task | Information to show first | Useful support |
|---|---|---|
| Understand a product | What it does and who it serves | One or two credible examples |
| Evaluate a plan | Price and applicable scope | Differences and conditions |
| Complete installation | Prerequisites and steps | Platform choices and troubleshooting |
| Learn a concept | Goals and central explanation | Examples, practice, next lesson |
| Resolve a problem | Search and topic categories | Related questions and return routes |

## Review in a useful order

- **Content:** Does the heading describe the page's purpose, and does the text explain necessary conditions?
- **Structure:** Do site navigation, categories, and article contents have distinct roles?
- **Visual hierarchy:** Do typography, spacing, borders, and color communicate clear levels?
- **Interaction:** Do search, switching, and expansion show state changes, with natural ways back?
- **Narrow layouts:** Is content ordered well, and do long headings or code crowd the page?
- **Accessibility:** Can the main flows be completed with a keyboard, with visible focus and clear text and controls?
- **Reliability:** Is content understandable when fonts, images, or video have not loaded?

After the first draft, walk through the main tasks using real content. Check whether hierarchy, navigation, and state feedback support each step.
