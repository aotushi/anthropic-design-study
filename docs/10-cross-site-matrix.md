# 10 跨站设计矩阵

**中文** · [English](en/10-cross-site-matrix.md)

[返回总览](../README.md) · [上一章：页面拆解](09-page-anatomy.md)

把站点放在一起看，可以分清哪些元素维持品牌一致性，哪些元素随任务变化。本章从阅读任务、字体角色和组件分布三个层次进行对照。

## 十个样本的阅读任务

| 样本 | 首要任务 | 主要空间组织 | 识别线索 |
|---|---|---|---|
| S01 公司官网 | 理解公司的关注点 | 大段主张与重点内容 | Sans 与 Serif 混排标题 |
| S02 产品介绍 | 认识产品用途 | 标题、主要动作与场景演示 | 产品任务与成果图像 |
| S03 定价 | 选择适合的方案 | 人群切换、套餐卡片与比较表 | 并列方案与明确的行动入口 |
| S04 资源中心 | 浏览或寻找内容 | 分类导航、搜索与卡片 | 浅网格、衬线大标题、线描插画 |
| S05 Academy 首页 | 选择学习方向 | 学习主题与卡片入口 | 产品配图与课程名称 |
| S06 课程内页 | 完成一节学习 | 目标、内容、章节与后续链接 | 课时标签与学习目标框 |
| S07 Code Docs | 开始使用开发工具 | 三栏阅读与安装选项 | Serif Display 标题、Paper Mono 代码 |
| S08 Platform Docs | 完成技术起步步骤 | 三栏阅读、编号步骤与代码 | 更紧凑的标题与 Anthropic Mono |
| S09 帮助中心 | 解决当前问题 | 搜索、主题集合与常见问题 | 问题导向的入口组织 |
| S10 开发者博客 | 扫描技术文章 | 主题筛选与文章行 | 等宽标签和像素图形 |

页面地址与证据文件见[来源索引](07-methodology-and-sources.md#页面来源索引)。

| Academy | Anthropic Serif | Anthropic Sans | 课时、章节和学习提示 |
| Code Docs | Anthropic Serif Display | Anthropic Sans | Paper Mono 代码 |

## 选择适合自己页面的组合

| 内容条件 | 可采用的组合 | 内容准备 |
|---|---|---|
| 内容多，读者目的不同 | 分类栏 + 搜索 + 卡片或文章行 | 清晰的类型、标题与摘要 |
| 操作有前后依赖 | 目录 + 编号步骤 + 代码复制 | 环境前提、操作结果与排错入口 |
| 需要比较几个方案 | 人群切换 + 套餐卡片 + 比较表 | 使用范围、差异与选择条件 |
| 需要循序学习 | 目标框 + 课时 + 章节 + 下一课 | 学习目标、练习与完成后的路径 |

先选择任务组合，再调整字体、色彩与密度，能把研究转化为有明确用途的界面方案。
